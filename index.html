💧 ¿Cuánta agua podemos ahorrar?

Calcula la duración de una reserva de agua antes y después de aplicar un porcentaje de ahorro.

Variables

V = Volumen almacenado (litros).
C = Consumo diario (litros/día).
A = Porcentaje de ahorro (%).

Modelo matemático

Días sin ahorro = Volumen / Consumo

Días con ahorro = Volumen / [Consumo × (1 - Ahorro / 100)]

🌿 Diseño del huerto óptimo

Modelado analítico y simulación geométrica para maximizar el área de cultivo bajo un perímetro perimetral fijo de P = 40 m.

Modelo Matemático (Cálculo I y Optimización)

• Relación de dimensiones: 2x + 2y = 40 ⇒ x + y = 20 ⇒ y = 20 - x
• Función de Área: A(x) = x(20 - x) = 20x - x²
• Optimización (Derivadas): A'(x) = 20 - 2x = 0 ⇒ x = 10 m (máximo absoluto con A''(x) = -2 < 0). Área máxima = 100 m².
